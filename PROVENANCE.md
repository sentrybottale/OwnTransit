# OwnTransit source provenance

OwnTransit is an independently implemented SSH-only transport. Its source and
documentation were written for this project from project requirements using
public standards, public library and API documentation, vendor-neutral
technical material, and publicly accessible descriptions of generic networking
patterns.

OwnTransit contains no knowingly incorporated proprietary source code,
binaries, user-interface assets, or documentation text. It does not implement
or require a private third-party protocol or API, and it does not claim
interoperability, affiliation, sponsorship, or endorsement by another
remote-access vendor.

Contributors must not submit material obtained through:

- decompilation, disassembly, circumvention, or extraction of a private
  third-party protocol;
- confidential, beta, support-only, employer-owned, or customer-restricted
  access;
- use prohibited by an agreement binding the contributor; or
- copying of third-party code, tests, documentation, diagrams, names, or visual
  assets without a compatible license and complete attribution.

Every contribution must be the contributor's original work or clearly identify
all third-party material and its license. A contribution must not expose trade
secrets, credentials, private endpoints, operational records, or another
party's confidential information.

## Contributor certification

Every commit must carry a `Signed-off-by` trailer certifying the
[Developer Certificate of Origin 1.1](https://developercertificate.org/). This
is a provenance statement, not a substitute for the Apache-2.0 license or for
required third-party notices.

## Release evidence

Each release must bind the reviewed source revision, reproducible build inputs,
SBOM, dependency-license inventory, project license, notices, artifact bytes,
and signatures. The complete private development record is retained separately
for authorized counsel and is never grafted into the public repository.

This document records development and contribution rules. It is not a patent
non-infringement opinion, trademark clearance, or legal advice.
